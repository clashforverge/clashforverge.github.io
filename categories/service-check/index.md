## 搜索到名称后，先做基础辨识

当搜索结果出现 **泰山net** 或 **taishannet** 时，先确认是否为同一名称的不同写法，再检查域名、公告账号、应用下载地址和更新记录是否彼此一致。只凭一个名称、截图或转发链接，无法判断服务主体、配置安全性或持续可用性。

相同的检查方式也适用于 **轻舟vpn**、**小猫vpn** 和 **木瓜云**。如果页面要求立刻导入未知文件、关闭系统安全提示、交出账户资料，或提供与官方渠道不一致的下载包，应停止继续操作并回到可验证的来源。

## 四步完成名称与链接核验

1. 比对官方页面、公告账号和客户端内显示的域名是否一致。
2. 阅读近期更新说明，确认时间、版本与平台支持信息没有明显矛盾。
3. 导入配置前创建备份，并在独立客户端中检查格式、策略组和日志提示。
4. 不将名称相似、搜索排名或单次测速结果视为安全或稳定性的证明。

名称核验完成后，如需了解 ClashMeta、Clash for Android 或 Windows 客户端如何导入配置，请阅读 [客户端与配置说明]({{ '/categories/client-config/' | relative_url }})。如需整理 Clash免费节点、节点推荐或飞机场节点的检查逻辑，可继续前往 [节点与订阅核验指南]({{ '/categories/node-guides/' | relative_url }})。
